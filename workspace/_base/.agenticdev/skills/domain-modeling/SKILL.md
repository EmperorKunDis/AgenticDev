# Domain modeling

Challenge ambiguous terms against the approved glossary and code. Test relationships with concrete edge cases. Record resolved domain language immediately without implementation details. Propose an ADR only for a hard-to-reverse, surprising decision with a real trade-off. Repository writes to CONTEXT or ADR files require an explicitly approved proposal PR.
