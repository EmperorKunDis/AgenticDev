# Research

Start with primary sources: official documentation, specifications, source code, and first-party APIs. Pin versions and access dates. Separate sourced facts from inference. Community reports may reveal failure modes but never authorize a security decision. Save concise findings and links in the project research ledger; never copy credentials, private transcripts, or copyrighted bulk text.
