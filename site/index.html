Vlastní platforma pro AI vývojové agenty. Oprávnění plynou z fáze projektu, agent běží v izolovaném kontejneru a každé rozhodnutí končí v auditovatelné evidenci. Self-hosted platform for AI coding agents. Permissions come from the project phase, the agent runs in an isolated container, and every decision lands in an auditable ledger.

Jak to nasaditHow to deploy it Zdrojový kódSource code

Server na jeden příkaz, stroje týmu přes odkaz s heslem. Co ještě nefunguje, píšeme níž. One command for the server, a password-protected link for your team's machines. What does not work yet is further down.

Proč vůbecWhy this exists

Většina nástrojů posadí agenta na notebook vývojáře a doufá. Tenhle to obrací. Most setups put the agent on the developer's laptop and hope for the best. This one inverts that.

01

Oprávnění z fáze, ne z osobyPermissions from the phase

V průzkumné fázi nikdo nesahá na zdrojáky — ne proto, že to zakazuje směrnice, ale protože je adresář připojený jen ke čtení. In discovery nobody touches source — not because a policy says so, but because the directory is mounted read-only.

02

Agent v kleciThe agent is fenced in

Běží v kontejneru bez cesty do internetu. Ven se dostane jen přes proxy, která pustí domény, které jsi vyjmenoval. It runs in a container with no route out. The only path is a proxy that allows the domains you listed.

03

Stopa, která zůstaneA trail that stays

Rozhodnutí, běhy i útrata padají do Postgresu na tvém serveru, ne do něčí historie chatu. Auditní stopa je navíc jen přírůstková a řetězená hashem — přepsat záznam zpětně databáze odmítne. Decisions, runs, and spend land in Postgres on your own server, not in someone's chat history. The audit trail on top of that is append-only and hash-chained — the database refuses to rewrite a record.

04

Bez účtu u násNo account with us

Jedna firma, jeden server, žádná centrální služba a žádná telemetrie. Že sis to nainstaloval, se nedozvíme. Účet ale budeš potřebovat u Tailscale — bez něj se platforma nedá bezpečně vystavit. One company, one server, no central service and no telemetry. We never learn that you installed it. You will need a Tailscale account though — without it the platform cannot be exposed safely.

Jak vypadá izolaceWhat the isolation looks like

Hranici drží jádro operačního systému, ne slušnost agenta. The boundary is held by the kernel, not by the agent behaving.

Git po síti dělá hostitel — agent nikdy nedrží přihlašovací údaje k repozitáři. Zápis mimo povolený rozsah skončí chybou souborového systému. Harness navíc odmítne pod spustit, když je kořen workspace zapisovatelný nebo chybí proxy: špatně nastavená izolace má spadnout nahlas, ne tiše nechránit nic. Network git operations stay on the host — the agent never holds credentials to your repository. A write outside scope fails at the filesystem. The harness also refuses to start the pod if the workspace root turns out to be writable or the proxy is missing: a misconfigured sandbox should fail loudly, not quietly protect nothing.

Z internetu je vidět jedna jediná cesta — registrační stránka, publikovaná přes Tailscale Funnel. Panel, git ani API veřejný port nemají. Heslo je na té stránce jediná zábrana, takže má omezený počet pokusů na adresu i celkem a po pěti neúspěších adresu na hodinu zamkne. Exactly one path is reachable from the internet — the enrollment page, published through Tailscale Funnel. The panel, git, and the API have no public port. The password is the only gate on that page, so attempts are limited per address and globally, and five failures lock an address out for an hour.

Tři až dvacet lidí, práce pro klienty, potřeba vědět, kdo na čem dělal a proč se to rozhodlo takhle. Three to twenty people, client work, and a need to know who did what and why it was decided that way.

Citlivá dataSensitive data

Projekt označíš jako chráněný a cloudové modely se pro něj tvrdě zakážou. Ne varováním — zákazem. Mark a project restricted and cloud models are hard-blocked for it. Not a warning — a refusal.

Kdo nechce cizí SaaSNo third-party SaaS

Kód klientů zůstává na tvém serveru a na strojích týmu. U nás se neregistruješ a nic nám neposíláš. Ven jde jen to, co si pustíš sám — model a domény, které vyjmenuješ. Client code stays on your server and your team's machines. You never register with us and send us nothing. The only things that leave are the ones you allow — your model and the domains you list.

Co k tomu potřebuješWhat you need

Nic exotického, ale Tailscale není volitelný — platforma se po veřejné síti nevystavuje. Nothing exotic, but Tailscale is not optional — the platform does not expose itself on the public network.

A VPS running Debian 12 or Ubuntu 22.04/24.04, and root. Memory scales with the team: ~2.5 GB for the stack plus ~1.5 GB per person working at the same time — the agents run here. Účet a zapnuté HTTPS certifikáty. Server ani databáze nemají veřejný port — všechno kromě registrace jde po tailnetu. An account with HTTPS certificates enabled. Neither the server nor the database has a public port — everything except enrollment goes over the tailnet.

Stroje týmuTeam machines

macOS, Linux nebo Windows. Stačí Tailscale a ikona na plochu — agent běží na serveru, takže na notebooku není Docker ani nic dalšího potřeba. macOS, Linux, or Windows. Tailscale and a desktop icon are enough — the agent runs on the server, so no Docker and nothing else is needed on the laptop.

ModelA model

Každý se přihlásí svým předplatným nebo klíčem, jednou. Útrata tak sedí tomu, kdo ji spotřeboval. U projektů s citlivými daty se cloud tvrdě zakáže a je potřeba lokální model. Each person signs in with their own subscription or key, once, so spend lands on whoever incurred it. For projects marked sensitive the cloud is hard-blocked and a local model is required.

Co ještě nefungujeWhat does not work yet

Je to alfa. Tohle nejsou překvapení, na která přijdeš týden po nasazení — jsou to díry, o kterých víme. This is alpha. These are not surprises you find a week in — they are holes we know about.

Testy si pouští agent sámThe agent runs its own tests

Mezi prací agenta a mergem není serverová brána. Pro malý tým, který si věří, to stačí; jako záruka kvality ne. There is no server-side gate between the agent's work and a merge. Fine for a small team that trusts itself; not a quality guarantee.

Agent pracuje bez stavového automatuNo orchestration layer

Orchestrační vrstva, která by řídila fáze úkolu, popsaná je, ale v kódu není. Server rozdává práci a kontext, ne postup. The layer that would drive a task through its stages is described but not implemented. The server hands out work and context, not a procedure.

Útrata je orientačníCost figures are indicative

Tokeny se odhadují, ceny modelů nejsou ověřené. Číslo v panelu ber jako ukazatel trendu, ne jako fakturu. Tokens are estimated and model prices are unverified. Treat the number in the panel as a trend, not an invoice.

Kontejner není hypervizorA container is not a hypervisor

Pod běží bez rootu, bez capabilit a bez docker socketu, ale útěk z kontejneru neřešíme. Je to pevný plot, ne trezor. The pod runs non-root, with no capabilities and no Docker socket, but container escape is out of scope. A strong fence, not a vault.

Heslo pro připojení nemá expiraciThe join password never expires

Je jedno pro celou instanci. Odvolat ho znamená změnit ho všem — jednotlivý stroj ale odebereš z panelu kdykoli. It is one password for the whole instance. Revoking it means changing it for everyone — though you can drop any single machine from the panel at any time.

Chybí observabilitaNo observability stack

Grafana a Loki jsou v compose zakomentované. Zatím platí logy z Dockeru a auditní stopa v databázi. Grafana and Loki are commented out in the compose file. For now it is Docker logs and the audit trail in the database.
